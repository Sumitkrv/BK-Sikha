# BK Shikha - Yogic Lifestyle & Wellness Mentor

A premium, production-ready React website for BK Shikha's Yoga & Wellness brand.

## 🌿 Brand Identity

- **Brand Name**: BK Shikha
- **Tagline**: Yogic Lifestyle & Wellness Mentor
- **Positioning**: Yogic Lifestyle Coach, Emotional Wellness Mentor, NLP Coach, and Mindset Mentor

## 🎨 Design System

### Color Palette
- **Primary**: #8B7355 (Warm Earth - grounding, trust, natural)
- **Secondary**: #A8C5A4 (Sage Green - calm, healing, growth)
- **Accent**: #D4A574 (Golden Sand - premium, wisdom, transformation)
- **Background**: #FAF8F5 (Warm Cream - peaceful, spacious, elegant)
- **Neutral**: #4A4A4A (Charcoal - sophistication, clarity)
- **CTA**: #7A9B76 (Deep Moss - action, vitality, nature)

### Typography
- **Headings**: Cormorant Garamond (serene, premium, spiritual)
- **Body**: Montserrat (clean, readable, modern)
- **CTA**: Montserrat Medium (clear, inviting)

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
